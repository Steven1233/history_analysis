# V2.0.0 更新方案

## 一、目标（共 9 项改动，覆盖原 4 项 + 新增 6 项）

**原有 4 项**

1. 跳出「执行进程」后返回无法实时刷新进度；
2. 各模块界面更便捷、流程更清晰；
3. 产出地图底图把广东省显示到**地市**级；
4. 检索配置新增「按目标日期的历史同期前后 x 天」（可手工自定义）。

**新增 6 项**

5. 检索范围可在地图上**矩形圈定**，经纬度参数实时回填；
6. 特征处理保留「不处理」选项（三选一）——同时解决「不标准化时量纲主导」问题；
7. 相似度定义可选：欧氏距离、余弦距离等，并支持**自定义公式**；
8. 直取要素场图改为**可选项**（单独出图）；
9. 结果中**每个时次各出一张空间概率图**。

> 原第 2 项「界面优化」把新增的 5/6/7/8 的控件一并纳入。

- **① 是真实缺陷**，四处根因已定位到行号（见下）。

## 第 6 项（新增）· 特征处理三选一（含量纲主导治理）

### 6.1 配置模型
- **替换** `standardize: bool`（[config.py L82](file:///e:/history_analysis/histsim/config.py#L82)）为 `feature_process: str = "none"`，取值 `none` | `standardize` | `normalize`：
  - `none`：不处理（保留可选项，用户明确要求）；
  - `standardize`：逐要素除以历史样本标准差（z-score，等价原 `standardize=True` 行为）；
  - `normalize`：逐要素 min-max 归一化到 `[0,1]`（`(H - min)/(max - min)`，`max==min` 时退化为不处理）。
- 量纲主导的治理依据：`u/v`（m/s，量级 1–10）与 `rh`（%，量级 10–100）等权相加时 `rh` 主导；选 `standardize` 或 `normalize` 即把各要素拉到同一量纲。界面上给出该提示文案。
- `validate()` 新增：`feature_process` 必须 ∈ 三个取值。
- `builtin_template()`：`plan_A` → `feature_process="none"`；`plan_B` → `feature_process="standardize"`（承接原 `standardize=True`）。

### 6.2 引擎（[engine.py L298-320](file:///e:/history_analysis/histsim/engine.py#L298-L320)）
`_build_features()` 的 `if cfg.standardize:` 改成分支：
```python
if cfg.feature_process == "standardize":
    sigma = float(np.std(H))
    if sigma > 1e-9:
        H, x = H / sigma, x / sigma
elif cfg.feature_process == "normalize":
    lo, hi = float(np.min(H)), float(np.max(H))
    if hi - lo > 1e-9:
        H, x = (H - lo) / (hi - lo), (x - lo) / (hi - lo)
```
（参数命名沿用现状：`H` 为历史矩阵、`x` 为目标向量。）

### 6.3 前端
- `index.html`（[L171](file:///e:/history_analysis/histsim/web/static/index.html#L171)）：删除「逐要素标准化」checkbox，改为 `<select id="cfgFeatureProcess">`（`none/standardize/normalize` 三个中文名），并在同分区加提示「不处理时量纲大的要素会主导相似度」。

| 取值 | 定义（`d = X - x`，`w` 为距离权重向量，`C` 为格点数） |
|---|---|
| `weighted_abs` | `Σ w·|d|`（现状保持） |
| `weighted_sq` | `Σ w·d²`（现状保持） |
| `euclidean` | `sqrt(Σ d²)`（**不含**距离权重） |
| `cosine` | `1 - (X·x)/(‖X‖·‖x‖)`（逐样本，含权重的距离权重不参与；由距离转距离度量使「越小越相似」口径统一） |
| `correlation` | `1 - corr(X, x)`，其中 `corr` 为两向量在格点轴上的 Pearson 相关（各自减去自身格点均值） |
| `custom` | 求值 `similarity_formula` |

### 7.2 受限公式求值器 —— 新建 `histsim/formula.py`
不执行任意代码，仅用标准库 `ast` 白名单遍历：

- 允许的 AST 节点：`Expression`、`BinOp(+ - * / ** // % ... 仅限算术)`、`UnaryOp(+ -)`、`Call`（`func` 必须是 `Name`）、`Name`（`Load`）、`Constant`（数值）。**其余一律拒绝**（无属性访问、无下标、无 lambda/推导式/赋值）。
- 可用变量：`d`（有符号逐格点差，形状 `(N, C)`，`N` 为历史样本数）、`w`（距离权重，形状 `(C,)`）、`n`（格点数）。
- 可用函数（映射到 numpy）：`abs sqrt exp log log1p minimum maximum power clip`；以及**沿格点轴归约**的 `sum`、`mean`（实现为 `np.sum(x, axis=-1) if x.ndim==2 else np.sum(x)`，`mean` 同理），保证结果是「每样本一个标量」。
- 对外接口：
  - `check_formula(expr) -> Optional[str]`：AST 校验，返回错误文本或 `None`；
  - `compile_formula(expr) -> Callable[[np.ndarray, np.ndarray], np.ndarray]`：返回 `f(d, w) -> si`；编译时用 `d=3×4` 的 dummy 试跑一次，若结果 `ndim != 1` 则抛 `ValueError("公式必须归约为每个样本一个数值，例如 sqrt(sum(w*d*d))")`；
  - `FORMULA_VARS` / `FORMULA_FUNCS` 供前端展示帮助；
  - `_self_check()`。
- 示例（写入界面占位符）：`sqrt(sum(w*d*d))`、`sum(w*abs(d))`、`sqrt(mean(d*d))`。

### 7.3 引擎（[engine.py L324-362](file:///e:/history_analysis/histsim/engine.py#L324-L362)）
- `_similarity_and_rank()` 开头 `formula_fn = compile_formula(cfg.similarity_formula) if cfg.similarity == "custom" else None`（**整轮只编译一次**）。
- 循环内 `diff = np.abs(X - x)` 改为 `diff = X - x`（有符号），并抽出 `_sim_scores(cfg, X, x, w_ord, formula_fn) -> np.ndarray` 做分派：
  ```python
  ad = np.abs(diff)
  if cfg.similarity == "weighted_abs":   return ad @ w_ord
  if cfg.similarity == "weighted_sq":    return (diff * diff) @ w_ord
  if cfg.similarity == "euclidean":      return np.sqrt((diff * diff).sum(axis=1))
  if cfg.similarity == "cosine":         return _cosine_dist(X, x)
  if cfg.similarity == "correlation":    return _corr_dist(X, x)
  return formula_fn(diff, w_ord)
  ```
  `_cosine_dist`/`_corr_dist` 内部做除零保护（范数为 0 时该样本记 `inf`，与现有 `excl_mask → inf` 语义一致）。
- 之后的 `si = np.where(excl_mask, np.inf, si)` / `argsort` 逻辑不变。
- `correlation` 需在格点轴（`axis=1`）减均值，注意被 `nan_to_num` 后的数据可直接算。

## 五、假设与决策

1. **圈选口径**：`SearchConfig.half_span_deg` 是单一半边长（正方形），而拖拽得到的是任意矩形 → 取 **`half_span_deg = max(半宽, 半高)`**，并把实际生效的正方形重绘回地图，做到所见即所得。
2. **圈选底图范围固定**为 `REGION_VIEW`（广东全省 + 0.6°），保证像素↔经纬度线性映射与 `/api/region/bounds` 一致；检索区不在广东时圈选仍可用，但底图只画广东。
3. **不引入前端依赖**：所有交互用原生 JS + pointer 事件实现（与现有 `app.js` 一致）。
4. **删除而非兼容 `standardize`**：项目为内部单机工具、模板与配置由本仓库生成，`SearchConfig.from_dict()` 会静默丢弃未知字段，无需兼容层。
5. **`euclidean`/`cosine`/`correlation` 不使用距离权重 `w`**（它们以整个格点场为对象），界面在相似度下拉旁标注。
6. **自定义公式只允许白名单 AST**，不提供 `eval/exec`，不允许属性访问与下标。
7. **24h 窗口与雨强单位**：沿用现状（`range(-2,22)`、逐时直接相加），本次不改，已知口径疑点仍留在说明文档中。
8. **不改变检索结果数值的项**：第 1、2、3、5、8、9 项只影响交互与出图；第 4、6、7 项会改变候选集/特征/排名数值，属预期。
